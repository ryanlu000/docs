Developer MCP is Ramp's specialized Model Context Protocol server designed for developers building with Ramp's API. It enables AI assistants to provide real-time API help, lookup schemas, and offer implementation guidance directly within your development workflow.

**Unlike other Ramp MCP servers, no Ramp account is needed.**

## Why Use Developer MCP?

- **Instant answers** to API questions without switching contexts
- **Up-to-date OpenAPI schemas** with related endpoint suggestions
- **Reduced documentation search time** so you can focus on building

## Setup

**Server URL:** `https://mcp.ramp.com/developer/mcp`

### Claude Desktop

Add to your Claude Desktop config file:

```json
{
  "mcpServers": {
    "ramp-developer": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://mcp.ramp.com/developer/mcp"]
    }
  }
}
```

### Claude Code

```bash
claude mcp add ramp-developer --transport streamable-http https://mcp.ramp.com/developer/mcp
```

## Available Tools

| Tool | Description |
|---|---|
| **Documentation Search** | Search Ramp's API docs using natural language queries |
| **Schema Retrieval** | Get the complete OpenAPI schema for any endpoint with related suggestions |
| **Feedback** | Report issues or suggest improvements directly |
