<Info>
  This guide assumes you are a Ramp customer with admin access to your dashboard. Need a test environment for development? [Request access to our Sandbox](/developer-api/v1/sandbox).
</Info>

## Step 1: Create a Developer App

First, create a developer app to get your API credentials.

<Steps>
  <Step title="Navigate to Developer Settings">
    In your Ramp account, go to **Company → Developer** (you'll need admin access).
  </Step>
  <Step title="Create a New App">
    Click **Create New App**. Name your app (e.g., "API Quickstart") and accept the Terms.
  </Step>
  <Step title="Configure Grant Types">
    Under **Grant types**, click **Add new grant type** → select **Client Credentials**.
  </Step>
  <Step title="Configure Scopes">
    Under **Scopes**, click **Configure allowed scopes** and select `transactions:read`.
  </Step>
  <Step title="Save Credentials">
    Copy your **Client ID** and **Client Secret**. Store them securely — you'll need them in the next step.
  </Step>
</Steps>

For more details on authorization, see the [Authorization Guide](/developer-api/v1/authorization).

## Step 2: Get an Access Token

With your credentials, request an access token. Ramp authenticates the `/developer/v1/token` request with HTTP Basic Auth: base64-encode `client_id:client_secret` and send it in the `Authorization` header.

```bash
curl --request POST \
  --url https://{environment-url}/developer/v1/token \
  --header 'Authorization: Basic {base64(client_id:client_secret)}' \
  --header 'Content-Type: application/x-www-form-urlencoded' \
  --data 'grant_type=client_credentials&scope=transactions:read'
```

Replace `{environment-url}` with:
- `https://demo-api.ramp.com` for Sandbox
- `https://api.ramp.com` for Production

<Warning>
  **API URLs are different from the Ramp app URLs.** The API base URL is not the same as the URL for the Ramp customer app. Make sure you're pointing your API calls at the API host, not the frontend host.
</Warning>

| Environment | API Base URL | App URL |
|---|---|---|
| Production | `https://api.ramp.com` | `https://app.ramp.com` |
| Sandbox | `https://demo-api.ramp.com` | `https://demo.ramp.com` |

**Response:**

```json
{
  "access_token": "ramp_tok_...",
  "token_type": "Bearer",
  "expires_in": 864000,
  "scope": "transactions:read"
}
```

Copy the `access_token` — you'll use it to make API calls. Tokens expire after **10 days**.

## Step 3: Make Your First API Call

With your access token, call the Ramp API to retrieve your transactions using the `GET /transactions` endpoint.

```bash
curl --request GET \
  --url https://{environment-url}/developer/v1/transactions \
  --header 'Authorization: Bearer {YOUR_TOKEN_HERE}'
```

That's it — you've made your first Ramp API call.
