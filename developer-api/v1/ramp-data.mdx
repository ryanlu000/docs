## Ramp Data MCP

Use Ramp Data MCP when you want an AI agent to explore datasets conversationally.

**Server URL:** `https://mcp.ramp.com/ramp-data/mcp`

### Claude Code

```bash
claude mcp add ramp-data --transport streamable-http https://mcp.ramp.com/ramp-data/mcp
```

### Cursor

Add to `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "ramp-data": {
      "url": "https://mcp.ramp.com/ramp-data/mcp"
    }
  }
}
```

### Claude Desktop

```json
{
  "mcpServers": {
    "ramp-data": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://mcp.ramp.com/ramp-data/mcp"]
    }
  }
}
```

## Available MCP Tools

### Ramp Rate Tools

| Tool | Description |
|---|---|
| `ramp_rate_list_categories` | List all software categories |
| `ramp_rate_get_category_summary` | Get adoption stats for a category |
| `ramp_rate_get_category_vendors` | Get ranked vendor leaderboard |
| `ramp_rate_resolve_vendor` | Resolve a vendor name to its canonical slug |
| `ramp_rate_get_vendor_profile` | Get a vendor's full profile |
| `ramp_rate_compare_vendors` | Compare 2-10 vendors side by side |

### AI Index Tools

| Tool | Description |
|---|---|
| `ai_index_get_adoption` | Get AI adoption history with vendor breakdown |
| `ai_index_get_adoption_by_sector` | AI adoption by industry sector |
| `ai_index_get_adoption_by_size` | AI adoption by company size |
