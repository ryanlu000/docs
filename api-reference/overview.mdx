## API Reference

The Ramp Developer API provides RESTful endpoints for managing corporate spend, cards, bills, accounting integrations, and more.

### Base URLs

| Environment | Base URL |
|---|---|
| Production | `https://api.ramp.com/developer/v1` |
| Sandbox | `https://demo-api.ramp.com/developer/v1` |

### Authentication

All API requests require a Bearer token in the `Authorization` header:

```bash
curl -H "Authorization: Bearer {access_token}" \
  https://api.ramp.com/developer/v1/transactions
```

See the [Authorization Guide](/developer-api/v1/authorization) for how to obtain tokens.
